# 🤖 AI That Doesn't Hurt the Budget
**"Local intelligence, professional results, zero bills."**

## 🧠 Bringing AI Home (Ollama)
Instead of sending every student essay to a giant corporation and paying them for the privilege, we brought the "Brain" directly into our software using **Ollama**.

### The Big Win: It’s Free.
*   **The Old Way**: Every time a student clicks "Grade," someone gets a bill. For a university, that adds up to thousands of dollars every year.
*   **Our Way**: We use the computers you already have. We ran Llama 3 locally, and it grades just as well as the paid stuff, but without the price tag.

## ⚡ The "ShadowQueue" (Our Safety Net)
Computers aren't perfect. Servers crash, and batteries die. If that happens during a massive final exam, it’s a nightmare.

We built the **ShadowQueue** to make sure that never happens. 
*   **It Never Forgets**: Every grading job is saved to the database the second it's created. 
*   **It Always Retries**: If the server blinks out, the second it wakes up, it picks up exactly where it left off.
*   **It’s Fast**: It handles hundreds of essays by organizing them into a tidy line, processing them one-by-one with maximum efficiency.

## 📊 Why This Matters
Real-world tech needs to be reliable and cheap. By moving AI away from expensive APIs and into a robust, local queue system, we've created a platform that actually works for schools, not against their budgets.
